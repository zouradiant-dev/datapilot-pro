# 评测发布边界

当前验证分支发布产品、通用评测合约与公开合成回归夹具，不发布封存 Holdout 的题目/Gold/原文、签名密钥、Permit、私密绑定或可重建正式试题的作者输入。

`tests/` 中的正式回归完整保留；它们通过 `scripts/` 的通用接口及 `tests/fixtures/` 的公开材料执行，不需要正式评测包。CI 的 Fake/HTTP Mock 和真实 PostgreSQL/MCP 测试不等于真实模型业务效果评测。

本机已有的独立评测作者/离线研究目录继续保留，不因本次发布而删除或改写，亦不随验证分支上传。历史 Seal、Gold、结果和凭据仍在被忽略的私密位置。需要复现正式评测时，必须另行取得准确版本的私密资产和相应授权；不能从缺失文件推断成功或补造来源。
