# P7 英文检索支持边界

**边界核验完成，英文可靠性质量 Gate 未通过。** 中文同语在本小样本正常；英文同语有成功也有错误空召回，且对措辞敏感；两个跨语言方向均没有足够证据承诺可靠支持。没有修改生产代码、语言准入、模型、阈值、Top-k、预算或默认策略。

## 当前可以声明什么

| 输入 → 文档 | 核心成对矩阵正例 | 本轮证据支持的范围 |
|---|---:|---|
| 中文 → 中文 | 2/2 召回 | 两个公开短文主题通过；不能外推所有中文经营问题 |
| 英文 → 英文 | 1/2 召回 | 工具层接受英文且能检索英文，但存在同语错误空召回；仅能描述为实验性/尽力能力 |
| 英文 → 中文 | 0/2 召回 | 不承诺可靠跨语言召回；不等于证明所有英文查询都会失败 |
| 中文 → 英文 | 0/2 召回 | 同上；语言一致性有帮助，也不是成功保证 |

另有两个英文措辞控制均召回，因此合并全部英文同语正例为3/4。它们与短问属于同一密钥轮换主题，且一个是已见 Dev 控制，**不能把3/4称为产品英文成功率75%**。来源不存在的中英文负例各1条，均空；两条属于同一人脸识别主题，不是两类独立负面业务。

建议产品说明披露“英文检索为实验性能力，暂不保证跨语言召回”。这是基于当前证据的文档边界，不是新增英文拒绝、自动翻译或静默查询改写。空结果只表示没有返回满足检索条件的授权片段，不能推断数据库没有该文档。网站自然语言意图、模型自主查询、Worker结束及最终Report英文质量本轮均未评测，不能据此宣称全站可靠支持英文。
